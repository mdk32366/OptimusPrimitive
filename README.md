# Optimus Primitive

We have a way to give a small general model a history — lived enough that, once it is in a robot, it cannot tell itself apart from a person who was there.

The test is from the inside. The first legend is invented. Matt's ear for what being there sounds like is how we know if it worked.

This repository is where we write that history and learn how to train it: the family bible, the year corpora, the adaptation, and the evaluation.

The working method is in [docs/training-spec.md](docs/training-spec.md).
